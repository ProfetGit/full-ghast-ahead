# Changelog

## 1.0.0 — 2026-09-23
- First release for Minecraft Java 26.2 and 26.3.
- A happy ghast flies 2× faster while a player steers it: forward, sideways, up and down. It goes back to vanilla speed the moment you get off, so unridden ghasts behave as before.
- Ops can pick 1×, 1.5×, 2×, 2.5×, 3× or 4× from a clickable menu: `/function full_ghast_ahead:settings`. The setting survives `/reload` and restarts.
